# VuraVision — نسخهٔ ۱.۱۴.۰

پروژهٔ کامل اندروید برای نمایشگر لمسی، همراه Gradle Wrapper و GitHub Actions.

## تغییرات این نسخه

۱. منوی اصلی، فایل، Undo، Redo و اشتراک به پایین راست، کنار دکمهٔ مخفی‌کردن ابزارها منتقل شدند. در صفحهٔ کوچک، کنترل صفحات در ردیف بالاتر قرار می‌گیرد.
۲. دکمه‌های بستن، افزودن آزمایش به تخته و کنترل‌های بازی و آزمایش در پایین قرار دارند. بازگشت به فهرست نیز در دسترس است.
۳. تصویر و PDF گزینهٔ تغییر رنگ ندارند؛ تصویر آزمایش هم همین رفتار را دارد.
۴. کراپ با کادر روشن و اطراف تیره، هشت گیرهٔ لبه و گوشه، جابه‌جایی کادر، بازنشانی و تأیید انجام می‌شود. نتیجه با Undo قابل بازگردانی است.
۵. زیرمنوهای معمول دکمهٔ بازگشت به منوی قبلی دارند.
۶. با زدن دوبارهٔ آیکون فعال انتخاب، تنظیمات آزاد/کادری باز می‌شود؛ پیش‌فرض آزاد است. هر حالت فقط محدودهٔ مخصوص خودش را نشان می‌دهد.
۷. کپی و پیست اشیاء تخته حذف شد. تکثیر با آیکون + باقی است. کپی لینک اشتراک و ورود محتوا از PDF، قابلیت‌های مستقل هستند.
۸. یک تا چهار بخش تخته، همگی ستون‌های عمودی کنار هم‌اند.
۹. طول خط هنگام رسم کنار خط‌کش نشان داده می‌شود. مقیاس بدون کالیبراسیون یک‌دهم قبل است: ۲۵۰ مختصات = ۲۵ واحد تخته.
۱۰. طول و زاویهٔ لازم برای گونیا، نقاله و پرگار به‌صورت زنده نمایش داده می‌شوند. سانتی‌متر واقعی از تنظیمات ← کالیبراسیون فعال می‌شود.
۱۱. ورود به اسنپ، خط آزاد ابتدای همان حرکت را حذف می‌کند. خروج از اسنپ تا برداشتن قلم رسم را متوقف می‌کند. پرگار از روی دایرهٔ دقیق شروع می‌کند؛ دستهٔ زرد مداد نقاله نیم‌خط می‌کشد و دستهٔ داخلی زاویه را بدون رسم تنظیم می‌کند.
۱۲. شمارهٔ صفحه و تعداد کل، مانند `1 / 12`، روی نوار پایین دیده می‌شود.
۱۳. منوی پای در تنظیمات معمول در دسترس است؛ پس از فعال‌سازی، با دکمهٔ نوار پایین یا دو ضربهٔ پنج‌انگشتی باز می‌شود. میان‌برها ذخیره می‌شوند.

## گرفتن APK از GitHub

فایل ZIP را باز کنید و **محتویات داخل آن** را در ریشهٔ مخزن جایگزین کنید؛ پوشهٔ `.github` هم باید آپلود شود. تنها آپلود ZIP باعث بیلد نمی‌شود.

همان چهار Secret قبلی را نگه دارید:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

با Push یا اجرای دستی **Android APK**، تست و بیلد انجام می‌شود. پس از موفقیت، artifact با نام `VuraVision-1.14.0-شمارهٔ اجرا` شامل APK و هش آن است. اجرای دستی، تست‌های دستگاه را نیز روی شبیه‌ساز اجرا می‌کند.

شناسهٔ بسته، فرمت `.vura` و روش امضا حفظ شده‌اند. برای نصب روی نسخهٔ قبلی، همان کلید امضای قبلی لازم است.

## وضعیت بررسی

بررسی ساختار سورس، XML، فونت‌ها، داده‌ها و نحو JavaScript انجام شد. در این محیط دانلود Gradle در دسترس نبود؛ بنابراین کامپایل اندروید، lint و تست‌های Robolectric این نسخه باید در GitHub Actions اجرا شوند و قبولی آنها اینجا ادعا نشده است. ۱۲ تست تازه در `Studio114Test.kt` اضافه شده‌اند. جزئیات در `docs/VERIFICATION_1.14.0.json` آمده است.

برای بررسی ژست‌ها و حس اسنپ، APK را روی نمایشگر واقعی آزمایش کنید. گزارش‌های قبلی صرفاً مربوط به نسخه‌های خودشان‌اند.
