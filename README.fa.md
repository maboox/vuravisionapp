# ویوراویژن ۱.۱۶.۰

سورس کامل اندروید، Gradle Wrapper و بیلد GitHub Actions برای نمایشگر لمسی.

فقط نوار اصلی منو، فایل، Undo، Redo و اشتراک پایین راست کنار پنهان کردن ابزارها قرار دارد. عملیات انتخاب آبجکت بالا یا کنار خودش باز می‌شود، پنجره‌های معمولی وسط هستند و بازگشت منوهای داخلی آیکون بالای پنجره است. دکمه‌های آزمایشگاه و بازی پایین می‌مانند. پای‌منو فقط از تنظیمات فعال و تنظیم می‌شود و با دو ضربهٔ پنج‌انگشتی باز می‌شود.

هر بخش تقسیم‌شده طرح و رنگ پس‌زمینهٔ مستقل دارد. برگشت به تک‌صفحه، تختهٔ تک‌صفحهٔ قبلی را برمی‌گرداند و نقاشی‌های تقسیم‌شده جدا حفظ می‌شوند. طول و زاویهٔ رسم با ابزار به صورت متن ماندگار می‌شود؛ اسنپ گونیا روی ضلع شروع می‌ماند و کنترل چرخش خط‌کش و شیب گونیا در دسترس است.

اتصال نقاط گراف و تقاطع‌ها، پاک کردن کشویی در پاک‌کن و میان‌بر Pie، آیکون‌های مستقیم مدیریت صفحه، تصویر کامل جدول تناوبی و تغییر نام بازیکن‌ها اضافه شده‌اند. آیکون‌ها با اندازهٔ UI تغییر می‌کنند. Undo پیش‌فرض ۵۰ و در تنظیمات مخفی قابل تنظیم است. تنظیمات انتخاب فقط از خود ابزار انتخاب باز می‌شود. [جزئیات نسخهٔ ۱.۱۶](docs/RELEASE_1.16.md) و [چک‌لیست دستگاه](docs/DEVICE_ACCEPTANCE_1.16.md) همراه سورس هستند.

## اتاق مشترک آزمایشی

از **تنظیمات ← پروفایل دستگاه**، نام، رنگ و ایموجی یا عکس را تعیین کنید. دسترسی اتاق: **تنظیمات ← دربارهٔ VuraVision ← دو ضربه روی لوگو ← انتظار ۱ تا ۳ ثانیه ← دوباره دو ضربه ← اتاق مشترک**.

یک دستگاه اتاق می‌سازد و بقیه از کشف خودکار، اسکن QR، عکس QR یا آدرس دعوت وارد می‌شوند. همه به یک وای‌فای، شبکهٔ محلی یا هات‌اسپات وصل باشند؛ QR آدرس اتاق را منتقل می‌کند و شبکه‌های جدا را به هم متصل نمی‌کند.

میزبان هر مهمان را با دسترسی مشاهده، کنترل یا همکاری تأیید می‌کند. مشاهده دنبال‌کنندهٔ میزبان و بدون ویرایش است؛ کنترل ابزار، صفحه، نما و Undo میزبان را مشترک می‌کند؛ همکاری ابزار و نمای مستقل و Undo شخصی دارد. خط زنده، نام و رنگ کاربر، قفل انتخاب، محوشدن آخرین حضور، حل تداخل، اتصال دوباره و بازیابی مهمان و انتقال عکس و PDF روی تخته اضافه شده‌اند. فضای جداگانهٔ مطالعهٔ PDF محلی می‌ماند.

این قابلیت آزمایشی است و باید روی دو دستگاه بررسی شود. جزئیات و چک‌لیست در [تغییرات نسخه](docs/RELEASE_1.15.md) و [آزمون دستگاه](docs/DEVICE_ACCEPTANCE_1.15.md) هستند.

## بیلد

ZIP را باز کنید و **تمام محتویات، از جمله پوشهٔ `.github`، در ریشهٔ ریپو** جایگزین کنید. فقط خود ZIP را داخل گیت‌هاب نگذارید. چهار secret امضای قبلی را حفظ کنید:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

Push یا اجرای دستی **Android APK** تست و بیلد را شروع می‌کند. پس از موفقیت، artifact با نام `VuraVision-1.16.0-شمارهٔ اجرا` شامل APK و هش است. شناسهٔ اپ و روش امضای نسخهٔ تولید تغییر نکرده‌اند.

بررسی ساختاری سورس، XML، داده و فونت انجام شده است. اجرای محلی بیلد اندروید با خطای شبکه هنگام دانلود Gradle متوقف می‌شود؛ بنابراین قبولی کامپایل، ۲۷۸ تست، lint و APK هنوز باید در GitHub Actions تأیید شود. گزارش فعلی [VERIFICATION_1.16.json](docs/VERIFICATION_1.16.json) است. گزارش‌های قدیمی، وضعیت تاریخی نسخه‌های قبلی هستند.
