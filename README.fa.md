# VuraVision — نسخهٔ ۱.۱۵.۰

پروژهٔ کامل اندروید برای نمایشگر لمسی، همراه Gradle Wrapper و GitHub Actions.

## اصلاحات چیدمان

۱. دکمهٔ پای‌منو از نوار ابزار برداشته شد؛ پای‌منو فقط در تنظیمات و با دو ضربهٔ پنج‌انگشتی باز می‌شود.
۲. منوها و پنجره‌های تنظیمات دوباره وسط صفحه باز می‌شوند.
۳. نوار ابزارِ آبجکتِ انتخاب‌شده دوباره کنار همان آبجکت (بالای آن، یا اگر جا نبود پایین آن) باز می‌شود و هنگام جابه‌جایی و حرکت تخته همراهش می‌رود.
۴. «بازگشت» به‌صورت آیکون در بالا و سمت شروع پنجره‌ها آمده است (در فارسی قرینه می‌شود)؛ دکمهٔ پایین فقط «بستن» است.
۵. نوار اصلی پایین (منو، فایل، Undo، Redo، اشتراک) و دکمه‌های داخل آزمایشگاه و بازی‌ها همچنان پایین‌اند.

## اتصال نمایشگرها (پیش‌نمایش، در بخش مخفی)

مسیر: درباره ← چند ضربه روی لوگو (ابزار مهندسی) ← «اتصال نمایشگرها (پیش‌نمایش)».

- **پروفایل**: نام، رنگ، اموجی یا عکس؛ فقط روی همین دستگاه ذخیره می‌شود و فقط برای افراد داخل اتاق نمایش داده می‌شود.
- **اتاق**: یک نمایشگر اتاق می‌سازد؛ بقیه از فهرست اتاق‌های نزدیک، با اسکن QR یا با واردکردن نشانی و کد وارد می‌شوند. با QR یا کد مستقیم وارد می‌شوند؛ با انتخاب از فهرست، صاحب اتاق اجازه می‌دهد.
- **نقش‌ها** (صاحب اتاق برای هر نفر تعیین می‌کند):
  - مشاهده: صفحه و نمای صاحب اتاق را دنبال می‌کند و تغییری نمی‌دهد.
  - کنترل: مثل حالت کست، روی همان تخته کار می‌کند؛ صفحه و نما و Undo مشترک است و جابه‌جایی صفحه دوطرفه است.
  - همکاری: هر تخته با ابزار، صفحه، نما و Undo خودش کار می‌کند؛ Undo هر نفر فقط کار خودش را برمی‌گرداند.
- **نمایش حضور**: هنگام کشیدن، خط زنده و نشانگر با نام دیده می‌شود؛ بعد از آن، حاشیهٔ محوی به رنگ همان نفر دور آخرین محل کار (و برای همکارها، محدودهٔ دیدشان) تا یک دقیقه کم‌رنگ می‌شود و می‌رود.
- **مالکیت انتخاب**: اولین کسی که آبجکتی را انتخاب کند صاحب آن است؛ بقیه دور آن خطی به رنگ و نام او می‌بینند و تا رها نشود نمی‌توانند انتخاب، جابه‌جا یا پاکش کنند.
- مهمان روی یک نسخه کار می‌کند و پس از خروج، درس خودش برمی‌گردد؛ می‌تواند نسخهٔ مشترک را در فایل‌های اخیر نگه دارد.

محدودیت پیش‌نمایش: هر دو دستگاه باید روی یک شبکه باشند (یک Wi-Fi یا هات‌اسپات یکی از دستگاه‌ها)؛ سرور اینترنتی ندارد. بخش PDF کنار تخته مشترک نمی‌شود (PDF به‌صورت شیء روی تخته مشترک می‌شود). جزئیات: `docs/RELEASE_1.15.md` و `docs/COLLABORATION.md`.

## گرفتن APK از GitHub

فایل ZIP را باز کنید و **محتویات داخل آن** را در ریشهٔ مخزن جایگزین کنید؛ پوشهٔ `.github` هم باید آپلود شود. تنها آپلود ZIP باعث بیلد نمی‌شود.

همان چهار Secret قبلی را نگه دارید:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

با Push یا اجرای دستی **Android APK**، تست و بیلد انجام می‌شود. پس از موفقیت، artifact با نام `VuraVision-1.15.0-شمارهٔ اجرا` شامل APK و هش آن است. اجرای دستی، تست‌های دستگاه را نیز روی شبیه‌ساز اجرا می‌کند.

شناسهٔ بسته، فرمت `.vura` و روش امضا حفظ شده‌اند. برای نصب روی نسخهٔ قبلی، همان کلید امضای قبلی لازم است.

## وضعیت بررسی

در این نسخه همهٔ سورس‌های Kotlin برنامه به‌صورت محلی با Kotlin 2.1.20 روی کلاس‌های API 35 اندروید، Gson واقعی و امضای سادهٔ بقیهٔ کتابخانه‌ها بررسی نوع (type-check) شدند؛ تست‌های جدید و تغییرکرده هم همین‌طور. قواعد همگام‌سازی در یک شبیه‌سازی سه‌دستگاهی اجرا و تأیید شدند. تست‌های اندروید، lint و ساخت APK امضاشده در GitHub Actions اجرا می‌شوند و اینجا قبولی آن‌ها ادعا نشده است. رفتار روی دو دستگاه واقعی را طبق `docs/DEVICE_ACCEPTANCE_1.15.md` بررسی کنید. جزئیات در `docs/VERIFICATION_1.15.0.json`.
