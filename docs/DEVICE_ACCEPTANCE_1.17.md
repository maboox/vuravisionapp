# آزمون نسخهٔ ۱.۱۷ روی دستگاه

این موارد هنوز روی نمایشگر واقعی یا دو تبلت اجرا نشده‌اند. قبولی تست‌های خودکار جای این مرحله را نمی‌گیرد.

- [ ] پروژهٔ واقعیِ قدیمی را باز کنید؛ عکس، PDF، حالت تک‌صفحه و نقاشی‌های تقسیم‌شده باقی مانده باشند.
- [ ] در چهار بخش با چهار رنگ و طرح پس‌زمینهٔ متفاوت بنویسید؛ به تک‌صفحه و دوباره چهار بخش برگردید. هیچ نقاشی ادغام یا حذف نشود.
- [ ] لمس قلم، سر ضخیم، کف دست، چند انگشت و لغو لمس در حاشیهٔ نمایشگر را با کالیبراسیون دستگاه بررسی کنید.
- [ ] وسط پاک‌کردن لمس را لغو کنید؛ سپس Undo/Redo بزنید. تصویر، ماسک پاک‌کن و تاریخچه درست برگردند.
- [ ] روی بورد شلوغ در رزولوشن اصلی نمایشگر بنویسید، پاک کنید، زوم کنید و Fit بزنید؛ محتوا زیر نوارها پنهان نشود.
- [ ] قلم فعال هر بخش را عوض کنید و با خط‌کش، گونیا، پرگار و نقاله رسم کنید؛ رنگ/ضخامت و متن ماندگار اندازه صحیح باشد.
- [ ] چند بار ذخیره، خروج، بازگشت و توقف برنامه را روی یک پروژهٔ بزرگ انجام دهید؛ آخرین ویرایشِ کامل‌شده حفظ شود.
- [ ] PDF چندصفحه‌ای با تصویرِ یادداشت را باز کنید؛ دو انگشت نباید جهش ایجاد کند. بعد از بستن/بازکردن فضای PDF، نما حفظ شود. خروجی را در یک PDF reader مستقل باز کنید.
- [ ] در بازی‌های زمان‌دار نام بازیکن را تغییر دهید و برنامه را پس‌زمینه ببرید؛ زمان توقف دوبار شمرده نشود. نگه‌داشتن همزمان دو انگشت با رهاشدن یکی تمام نشود.
- [ ] زبان فارسی/انگلیسی و UI کوچک/بزرگ را روی نمایشگر مقصد امتحان کنید؛ منوی اصلی پایین، منوی آبجکت کنار آن و بازگشت بالای پنجره باشد.
- [ ] دو دستگاه روی یک Wi-Fi/هات‌اسپات: کشف و QR، تأیید میزبان، حالت مشاهده/کنترل/همکاری و محدودیت ویرایش را بررسی کنید.
- [ ] دو نفر همزمان رسم و انتخاب کنند؛ قفل انتخاب، Undo شخصی همکاری و Undo مشترک کنترل درست باشد.
- [ ] درست قبل از پایان اتاق یک خط روی میزبان بکشید؛ ذخیره و بازکردن پروژه باید آن خط را حفظ کند.
- [ ] قطع و وصل Wi-Fi، خروج مهمان و برگشت مهمان را امتحان کنید؛ تغییرات تکراری یا تصویر خراب ایجاد نشود.
- [ ] APK امضاشدهٔ GitHub Actions را روی نسخهٔ قبلی نصب کنید؛ شناسهٔ برنامه و امضای قبلی ثابت باشد و داده‌ها حفظ شوند.

اتاق از بخش مخفی در دسترس است. QR فقط آدرس اتاق را منتقل می‌کند؛ ارتباط دو شبکهٔ جدا بدون سرویس واسط پیاده‌سازی نشده است.
