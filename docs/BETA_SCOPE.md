# Release scope

The later request to finish at least a beta governs this release. The preserved original specification is not marked complete.

| Area | Delivered | Deferred / qualification needed |
| --- | --- | --- |
| Foundation | Kotlin native app, SDK 35, real Gradle wrapper, CI and beta APK | Production signing/distribution; device matrix |
| Board | Multi-pointer ink, undo, transforms, pages, selection, object locks | Lasso, segment erasing, persistent groups, latency benchmark |
| Lessons | Asset-bearing archives, checked imports, atomic saves, backup recovery | Asset garbage collection, historical schema migrations |
| Media | Images, multipage PDF objects, crop, PDF/PNG/JPEG export | Editable PDF text, lossless embedded PDF, huge-document optimization |
| Recognition | English/Persian ML Kit models and reviewed text insertion | Field accuracy validation, equation-layout OCR |
| Mathematics | Typed expressions, curves, linear equations | Symbolic algebra, full formula editor |
| Classroom | Eight labs, eight games, timer/scoreboard/dice/curtain, PDF QR | Remaining catalog, overlays over other apps |
| Localization | English/Persian resources and RTL switching | Full accessibility and device typography audit |
| Diagnostics | Raw hardware metrics, explicit calibration thresholds, stress sample | Vendor-specific profiles and measured latency |

The implementation does not present mock recognition results, fabricated hardware measurements or the remainder of the catalog as completed features.
