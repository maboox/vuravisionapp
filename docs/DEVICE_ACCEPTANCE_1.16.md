# Device acceptance · VuraVision 1.16.0

These checks are pending; use the GitHub-built APK on the intended touch display/tablet. Also run DEVICE_ACCEPTANCE_1.15.md for experimental rooms.

1. Draw on a solo board, change its background/camera, then enter split 4. Give each panel a different color **and pattern**, draw in all four, reduce to 2/3, return to 4. Hidden drawings must stay in their own panels. Return to 1: the original solo content/settings return without split drawings. Change solo content; reopening split restores its own content. Save/reopen and duplicate the page; repeat with images and layers in the dormant workspace. Undo/Redo the mode switches. Export 4 panels to PNG/PDF and check full-height vertical columns.
2. Select a graph/function, photo/PDF, ruler and other guides: color must be absent. Mixed graph+text selection should recolor text only. On a blank coordinate graph add (-2,-2), (2,2), (-2,2), (2,-2); enable Connect points in order, find intersections: (0,0) is separate from the four input points. Try a horizontal point segment at y=1 against x²: crossings near x=±1. Toggle connections or edit points/functions; stale markers must clear. Save/reopen and inspect export.
3. Ruler: rotate using ↻, resize, draw near either edge and try Parallel / Perpendicular in More. Only one parallel construction entry is present. Length text remains after release and moves/edits like ordinary text. Undo removes both drawing and text. Repeat with calibrated cm and split-panel pen colors/widths.
4. Draw along a set-square diagonal into its vertex and drag along another side without lifting. No adjoining-edge scratch may be added. Lift and start a new contact on that side; it should work. Change slope with ∠ and More → slope, rotate the guide and resize it. Numbers should remain proportional/readable.
5. Compass: set radius/start, draw an arc, leave its magnetic area and re-enter without lifting. Drawing must stop on leaving. Radius/sweep text remains; Undo also restores the guide. Protractor pencil handle draws a ray and leaves angle/length text. Repeat edge snapping for all guides, including contacts beginning off-guide. Free prefix and off-guide tail must not remain.
6. Select a mind-map node: no smart/text-recognition/math/shape actions and no ambiguous child/sibling plus controls. Use named child/sibling commands and edit text/color; connectors and grouped duplication still work.
7. In the periodic table add the complete image; all 118 elements, including detached f-block rows, must appear. Resize/crop/save/export it as a regular image. Interactive table and individual cards remain available.
8. Eraser: partial slide, tap, second finger and cancel must do nothing. Complete slide + release clears editable contents once. In split mode only the active panel is cleared. Locked items/layers and PDF source stay protected. Undo restores items. Assign Clear page to Pie and verify the same slider is used. Check both Persian RTL and English LTR.
9. Pages: direct Duplicate/up/down/Clear/Delete icons beside previews. First/last movement and last-page delete disable correctly; switching preview stays a single tap. Clear/Delete confirm. Reordering a different page preserves the current page. Duplicate an archived split board and verify internal mind-map connections use new IDs.
10. UI sizes Small/Medium/Large: icon drawings, labels and controls scale together. Main actions stay bottom-right, object actions remain near the selection, dialogs centered and Back icons at the top. Use selection settings from the Select icon; no duplicate normal-settings entry.
11. Hidden Engineering → Undo history limit: default 50; test 10, 25, 50, 100, 200 on board/PDF annotations. In rooms verify host/control share the configured host history while collaborators keep independent authorship.
12. Native and legacy games: tap names before/during/after rounds, use Persian/English names, cancel/reset, restart/open another game. Names persist locally and appear in turn/result labels. Editing should pause timed progress and clear stale held contacts without losing scores.
