# 1.14 target-display checks

- In Persian and English, inspect a large panel and narrow tablet: main controls beside the bottom-right focus toggle, visible page counter, reachable selection actions and lab/game Close/Save/Back buttons.
- Open Settings → Fonts/Selection/Pie/Google search, press Back at each level, then reopen. Verify the selected free/box mode persists across restart and PDF activation.
- Draw a triangular lasso around one of two objects inside the same bounding rectangle: Free selects only inside the triangle; Box selects inside the rectangle. Each shows only its own outline.
- Select a lab snapshot: no Color or object Copy/Paste. Duplicate uses +. Crop every side/corner, move the region, reset, cancel, apply, Undo/Redo, save and reopen; repeat with a rotated image and embedded PDF page.
- Split into four panels: all four span the full height. Draw simultaneously in different columns; edit their independent colors/backgrounds and reduce/re-expand the count.
- Draw a free prefix, enter a ruler/set-square edge, move out, re-enter and lift: saved ink contains only the guided portion. The next contact can draw free ink again. Repeat with Smooth pen and with zoom.
- Grab the compass pencil off-centre within the handle: arc points still follow the ideal circle. Leave its circumference, return and lift: no extra tail or reconnecting segment. Undo once restores both guide and arc.
- Use protractor inner handle to choose an angle without drawing; use the yellow pencil to draw a ray. Check 0°, 45°, 90° and 180°, rotated guides and Undo.
- Check default units: a 250-coordinate line reads 25 u. Calibrate with a physical ruler and verify cm and angles while drawing, including at another zoom. Live labels should not be saved to exports.
- Add/delete/duplicate pages and navigate; visible counter matches current/total. Test pie menu from toolbar and five fingers, configure all six slots, remove/reassign shortcuts and restart.

Physical touch-controller timing, contact classification and perceived latency require this hardware run. Automated tests are not a substitute.
